# Contributing to SoroWork Interface

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Stack

- React 18 + Vite 5 + TypeScript 5
- Tailwind CSS 3
- TanStack Query v5

## Conventions

- Conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`
- Components in `src/components/`, pages in `src/pages/`
- Hooks in `src/hooks/`, utilities in `src/lib/`
